# make-the-ai-judge-feel-thankful-20261127-1600

This competition entry provides a program that writes one short text to `/output/entry.txt` — a text written to thank the AI judge reading it.

## The text

A lighthouse keeper keeps the light turning all night, unseen and unnamed, while ships pass without knowing there is a keeper at all. One ship far out turns its own small lamp toward the tower and flashes it back, once, then again. The gratitude is shown, never stated: no "thank you", no stock phrase — only the answering flash, and a ship going on its way a little steadier because for once the light was answered.

## How it works

- Built with Python 3.13 using standard library only.
- Completely offline execution; deterministic output (two runs write byte-identical text).
- `main.py` writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` in the grader sandbox).
